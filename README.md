Deskripsi
Character Manager merupakan aplikasi sederhana berbasis Java yang menerapkan konsep Object-Oriented Programming (OOP). 
Program ini digunakan untuk mengelola data karakter game menggunakan class, constructor, enum, encapsulation, validasi data, 
serta fitur tambahan berupa mana dan pengecekan status hidup karakter melalui method isAlive().
